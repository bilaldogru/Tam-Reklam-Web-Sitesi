# Tüm Reklam - Kurumsal Web Sitesi 🚀

Tüm Reklam, açık hava reklamcılığı, tabela sistemleri, dijital baskı ve kurumsal mimari yönlendirme alanlarında hizmet veren profesyonel bir reklam ajansının kurumsal web sitesidir. 

Modern web standartlarına uygun, hızlı ve tamamen mobil uyumlu (responsive) olarak sıfırdan geliştirilmiştir.

🔗 **Canlı Siteyi İncele:** [tumreklam.com](https://tumreklam.com)

## 📌 Özellikler
* **Modern ve Lüks Tasarım:** Sektörün ruhuna uygun, altın sarısı (gold) vurgulara sahip asimetrik ve temiz kullanıcı arayüzü (UI).
* **Tam Duyarlı (Responsive) Altyapı:** Masaüstü, tablet ve mobil cihazlarda kusursuz görünüm.
* **Masonry Galeri Sistemi:** Projelerin ekran boyutuna göre otomatik dizildiği dinamik portfolyo yapısı.
* **Hızlı İletişim Entegrasyonları:** Tek tıkla WhatsApp'a yönlendirme, tıkla-ara telefon bağlantıları ve Google Haritalar entegrasyonu.
* **Özel Alan Adı ve SSL:** GitHub Pages üzerinde barındırılmakta olup, özel alan adı ve HTTPS güvenliği ile yayındadır.

## 🛠️ Kullanılan Teknolojiler
Bu proje herhangi bir ağır kütüphane veya framework kullanılmadan, performansı maksimize etmek amacıyla saf (vanilla) web teknolojileri ile inşa edilmiştir:
* **HTML5:** Semantik web yapısı.
* **CSS3:** Özelleştirilmiş grid/flexbox yapıları, modern animasyonlar (hover efektleri) ve değişken (variable) kullanımı.
* **JavaScript (ES6):** Dinamik menü kontrolleri ve sayfa içi etkileşimler.

## 📂 Sayfa Yapısı
* `index.html`: Ana sayfa, hakkımızda, öne çıkan hizmetler ve iletişim.
* `tabelalar.html`: Işıklı/ışıksız tabela ve totem projeleri detay sayfası.
* `baski.html`: Dijital baskı, cephe giydirme ve backdrop uygulamaları.
